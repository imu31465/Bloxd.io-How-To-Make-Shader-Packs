# 研究记录

> 状态：Analyzed

本页说明如何阅读有关游戏实现的技术说明。内部行为并非公开 API 契约，可能随游戏更新而改变。

## 研究原则

1. **检查可观察行为** — 将文档与游戏内验证及运行时行为进行对照。
2. **区分实现与 API** — 区分着色器包可使用的功能与仅供引擎内部使用的机制。
3. **说明结论来源** — 记录某项数值或行为来自引擎中的哪项处理。
4. **不要把推断写成事实** — 区分观察到的事实、解释和未解决的问题。
5. **不要把观察时间当成发布时间** — 调查期间进行的检查不能证明某项功能何时开始分发。
