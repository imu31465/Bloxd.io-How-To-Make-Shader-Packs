# API v1

> 状态: **Historical** — 着色器包机制的第一个时代。所有 v1 包都会被当前游戏拒绝。

v1 是第一个着色器包 API。v2 全面改换了标识符 ([v2 指南](v2.md) §32 的表格)，因此了解 v1 词汇的主要价值是**阅读旧分发物与旧社区指南**。

## v1 词汇 (v2 中改名)

| v1 | v2 起 |
|---|---|
| `bloxdTime()` | 同名 (v3 中成为 `bloxdSeconds()`) |
| `bloxdOriginOffset()` | 同名 (v3 中成为 `bloxdRenderOffset()`) |
| `bloxdFaceBlock(position, normal)` | 同名 (v3 中移除) |
| `fogFactor` | `fogVisibility` (v5 中成为 `fogAlpha`，语义反转) |
| `engineColour` | 同名 (v5 中移除 — 重构为 `litColour` 与 `bloxdLitColour()`) |
| — | `blockId` (v2 中加入，v3 中成为 `blockFlags`) |

钩子为 terrain / liquid × vertex / surface — **6 个钩子**，没有 light 钩子 (light 钩子在 v5 才进入默认模板)。方块识别只能靠纹理颜色猜测；`blockId` / `blockFlags` / `flags` 尚不存在。
