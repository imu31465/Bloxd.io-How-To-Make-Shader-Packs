# 版本历史

> 类型：历史资料 · API v1–v5 迁移指南

本节保存 v1 至 v5 的变更、迁移步骤和已移除的 API。内容侧重 API 行为和迁移路径，不记录构建标识或验证日期。

## 版本

| 版本 | 迁移指南 | 主要变更 |
|---|---|---|
| v1 | [v1](v1.md) | 着色器包初始 API |
| v2 | [v2](v2.md) | 标识符重命名、`blockId` 和场景深度访问 |
| v3 | [v3](v3.md) | `blockFlags`、`bloxdPi` / `bloxdTau` 和 Liquid 钩子 |
| v4 | [v4](v4.md) | 纹理 API 和 strict 游戏限制 |
| **v5** | [v5](v5.md) | **当前版本** — `BloxdFlags`、Model 钩子、光照 API 和阴影 API |

## 旧版本的处理方式

当前游戏只接受 `apiVersion: 5` 的着色器包。旧版本的包无法在不修改的情况下加载。跨多个版本迁移时，请从最旧的版本开始，按顺序应用各迁移指南。
