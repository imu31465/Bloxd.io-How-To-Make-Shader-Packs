# Bloxd.io 着色器包开发文档

这是一份面向 Bloxd.io WebGPU 渲染器着色器包的非官方指南，涵盖制作、实现、验证与发布，以及 API 规范和引擎内部机制分析。

## 当前规格

- 当前 API：**5**（`pack.json` 必须声明 `apiVersion: 5`）
- 目标：WebGPU 渲染器
- 着色器钩子：9 个（Terrain / Liquid / Model × Vertex / Surface / Light）

初次制作着色器包请从[入门指南](getting-started/)开始；查询 API 请看 [API 参考](api/)。

> 本文档不是游戏开发方的官方资料。引擎内部机制属于实现细节，可能随更新变化；受支持的功能以 API 参考为准。
>
> 本指南在编写过程中使用了 AI 辅助。引擎实现细节可能随更新变化，请以游戏中的实际行为为准。
>
> 着色器包仅使用 WGSL 编写，不会执行 JavaScript，也不会发起网络请求。

## 文档结构

- **[入门指南](getting-started/)** — 概览、快速开始、包结构、pack.json、9 个钩子、变体、验证、分发。
- **[API 参考](api/)** — 当前 API v5 的系统规格：钩子、标志、输入/输出结构体、全部函数、光照、纹理 API、常量、预处理器、限制、兼容性、包含 1,017 个纹理标识符的目录。
- **[指南](guides/)** — 光照原理、阴影、水、夜晚、模型渲染、性能、写实思路。
- **[实战配方](recipes/)** — 按目的组织的代码示例：颜色、光照、自发光、坐标、动画、液体、顶点、数学、写实化、模型着色器、附魔效果。
- **[故障排查](troubleshooting/)** — 按症状组织的排错：加载、API 版本、编译、验证、变体、画面、纹理、光照、模型、性能。
- **[引擎内部](internals/)** — 渲染管线、钩子接入、引擎标头、验证与编译内部、保留标识符、光照/雾内部、纹理采样与注册表、模型渲染、实测数据。
- **[版本历史](history/)** — v1 到 v5：各版本变更、迁移步骤、废弃 API。
