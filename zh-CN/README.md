# Bloxd.io 着色器包开发文档

关于 Bloxd.io 的 WebGPU 渲染器着色器包的非官方文档——从创建、实现、验证、分发，到 API 规格与引擎内部研究。

## 当前规格

- 当前 API：**5**（`pack.json` 必须声明 `apiVersion: 5`）
- 目标：WebGPU 渲染器
- 最后验证：2026-11-05
- 目标构建：`v98qt8.main.62d8d238.js`（生产与 preprod，2026-11-08 验证，字节相同的 bundle，md5 `7458fd47ff88331d9f451d1456ff48ac` — 注册表、头部、钩子、限制已重测）
- 着色器钩子：9 个（Terrain / Liquid / Model × Vertex / Surface / Light）

初次制作着色器包请从[入门指南](getting-started/)开始；查询 API 请看 [API 参考](api/)。

> 本文档不是游戏开发方的官方资料。引擎内部规格可能随更新变化——请确认各页面标注的目标构建与验证状态。
>
> 本指南借助 AI 协助编写，准确性不作保证。请以实际游戏行为为准验证；也请持续对照加载器界面与游戏内编译来复核配方。
>
> 着色器包功能本身是游戏内 UI 提供的官方功能，包是纯 WGSL（无 JS 执行、无网络访问），正常编写不会产生危险行为。

## 文档结构

- **[入门指南](getting-started/)** — 概览、快速开始、包结构、pack.json、9 个钩子、变体、验证、分发。通向第一个包的单线教程。
- **[API 参考](api/)** — 当前 API v5 的系统规格：钩子、标志、输入/输出结构体、全部函数、光照、纹理 API、常量、预处理器、限制、兼容性、911 个名称的纹理目录。
- **[指南](guides/)** — 光照原理、阴影、水、夜晚、模型渲染、性能、写实思路。
- **[实战配方](recipes/)** — 按目的组织的代码示例：颜色、光照、自发光、坐标、动画、液体、顶点、数学、写实化、模型着色器、附魔效果。
- **[故障排查](troubleshooting/)** — 按症状组织的排错：加载、API 版本、编译、验证、变体、画面、纹理、光照、模型、性能。
- **[引擎内部机制与研究](internals/)** — 渲染管线、钩子接入、引擎标头、验证与编译内部、保留标识符、光照/雾内部、纹理采样与注册表、模型渲染、实测数据。
- **[版本历史](history/)** — v1 到 v5：各版本变更、迁移步骤、废弃 API。
