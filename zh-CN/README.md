# Bloxd.io 着色器包制作方法 (完整版)

自包含的 Bloxd.io 着色器包 (仅 WebGPU 渲染器) 制作与分发指南。
**现行 API 为 `apiVersion: 4` —— 已于 2026-10-26 正式上线**，当前游戏在加载时会拒绝 v1、v2 与 v3 包 (API 版本不符消息)。下文中第一至第七部分仍以 v2 为基准撰写，作为概念基础继续有效——请按 v2 阅读，然后在分发前应用第九部分 (`09-apiv3.md`) 与第十部分 (`10-apiv4.md`) 的变更。第十部分涵盖 v4 的纹理 API (`bloxdTexel`、`bloxdTextureId*`)、雾字段改名 (`fogAlpha`，含义反转！) 以及严格游戏契约。指南按部拆分为独立文件 (本 README 为目录；配方集在 `03-recipes.md`)。更早的 v1 → v2 迁移见第八部分 (`08-apiv2.md`)。第九部分还记录了从生产构建复原的引擎内部实现 (§49–§54: 钩子调用、四模式雾函数、`bloxdOpaqueBehind()` 实现、blockFlags 传递路径，以及带实测标头哈希的验证管线)。

> 本书为非官方指南，不代表开发者的官方立场。API 可能随时变更。  
> 本指南在 AI 协助下创建，不保证准确性。请以实际游戏表现为准。  
> 最后检查: 2026-10-27 (已确认 v4 上线 —— 构建 `cnty9`，生产与预发布一致；见第十部分。 通过对比构建确认 v3 已正式上线；钩子调用、雾、深度与 blockFlags 内部实现均从生产构建复原——第九部分 §49–§54)。完整参考材料已作为第十一部分 (`11-reference.md`) 嵌入——逐字复原的引擎头文件与含全部 905 个可用纹理名称的完整实测目录；API 说明与配方仍请持续以加载界面与游戏内编译为准。  
> 着色器包功能本身是游戏内 UI 可加载的官方功能，包为纯 WGSL  
> (无 JS 执行、无网络通信)，正常代码不会发生危险。
