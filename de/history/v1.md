# API v1

> Status: **Historical** — die erste Ära des Shader-Pack-Mechanismus. Jedes v1-Paket wird vom aktuellen Spiel abgelehnt.

v1 war die erste Shader-Pack-API. v2 benannte die Bezeichner komplett um (Tabelle im [v2-Leitfaden](v2.md) §32), daher ist der Hauptwert, die v1-Vokabel zu kennen, **das Lesen alter Distributionen und alter Community-Guides**.

## v1-Vokabular (in v2 umbenannt)

| v1 | ab v2 |
|---|---|
| `bloxdTime()` | gleich (wurde in v3 `bloxdSeconds()`) |
| `bloxdOriginOffset()` | gleich (wurde in v3 `bloxdRenderOffset()`) |
| `bloxdFaceBlock(position, normal)` | gleich (in v3 entfernt) |
| `fogFactor` | `fogVisibility` (wurde in v5 `fogAlpha`, invertiert) |
| `engineColour` | gleich (in v5 entfernt — umstrukturiert in `litColour` und `bloxdLitColour()`) |
| — | `blockId` (in v2 hinzugekommen, wurde in v3 `blockFlags`) |

Hooks waren Terrain / Liquid × Vertex / Surface — **6 Hooks**, keine Light-Hooks (Light-Hooks wurden erst in v5 Teil der Standard-Vorlage). Block-Identifikation war reines Texturfarben-Raten; `blockId` / `blockFlags` / `flags` existierten noch nicht.
