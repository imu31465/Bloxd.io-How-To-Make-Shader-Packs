# 버전 히스토리

> 유형: 기록 · API v1~v5 마이그레이션 가이드

이 섹션은 v1부터 v5까지의 변경 사항, 마이그레이션 단계, 제거된 API를 보존합니다. 빌드 식별자나 검증 날짜가 아니라 API 동작과 마이그레이션 경로를 설명합니다.

## 버전

| 버전 | 마이그레이션 가이드 | 주요 변경 사항 |
|---|---|---|
| v1 | [v1](v1.md) | 셰이더 팩 초기 API |
| v2 | [v2](v2.md) | 식별자 이름 변경, `blockId`, 씬 깊이 접근 |
| v3 | [v3](v3.md) | `blockFlags`, `bloxdPi` / `bloxdTau`, Liquid 훅 |
| v4 | [v4](v4.md) | 텍스처 API, strict 게임 제한 |
| **v5** | [v5](v5.md) | **현재 버전** — `BloxdFlags`, Model 훅, 라이팅 및 그림자 API |

## 이전 버전의 처리

현재 게임은 `apiVersion: 5`인 팩만 허용합니다. 이전 버전의 팩은 그대로 로드할 수 없습니다. 여러 버전을 거쳐 마이그레이션할 때는 가장 오래된 버전부터 각 가이드를 순서대로 적용하세요.

## 마이그레이션 경로

- v4 팩 → [v5 마이그레이션 가이드](v5.md)
- v3 팩 → [v4](v4.md) → [v5](v5.md)
- v2 팩 → [v3](v3.md) → [v4](v4.md) → [v5](v5.md)
- v1 팩 → [v2](v2.md) → [v3](v3.md) → [v4](v4.md) → [v5](v5.md)

현재 API는 [API 참조](../api/)에서 확인하세요.
