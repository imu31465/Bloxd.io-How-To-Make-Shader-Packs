# API v1

> 상태: **Historical** — 셰이더 팩 기구의 첫 시대. 모든 v1 팩은 현행 게임이 거부한다.

v1 은 최초의 셰이더 팩 API 다. v2 가 식별자를 전면 개명했으므로 ([v2 가이드](v2.md) §32 의 표), v1 어휘를 아는 주된 가치는 **옛 배포물과 옛 커뮤니티 가이드를 읽는 것** 이다.

## v1 어휘 (v2 에서 개명)

| v1 | v2 이후 |
|---|---|
| `bloxdTime()` | 같음 (v3 에서 `bloxdSeconds()` 로) |
| `bloxdOriginOffset()` | 같음 (v3 에서 `bloxdRenderOffset()` 로) |
| `bloxdFaceBlock(position, normal)` | 같음 (v3 에서 제거) |
| `fogFactor` | `fogVisibility` (v5 에서 반전된 `fogAlpha` 로) |
| `engineColour` | 같음 (v5 에서 제거 — `litColour` 와 `bloxdLitColour()` 로 재구성) |
| — | `blockId` (v2 에서 추가, v3 에서 `blockFlags` 로) |

훅은 terrain / liquid × vertex / surface — **6훅**. light 훅은 없었다 (light 훅이 기본 템플릿에 들어간 것은 v5 부터다). 블록 식별은 텍스처 색 추측뿐. `blockId` / `blockFlags` / `flags` 는 아직 존재하지 않았다.

## v1 → v2 이주

전면 개명이므로 기계적 변환이 아니다. [v2 마이그레이션 가이드](v2.md) 를 처음부터 읽어라:

1. [§31 v1 팩의 운명](v2.md)
2. [§32 식별자 개명 (표)](v2.md)
3. [§33 제거된 필드의 행선지](v2.md)
4. [§37 v1 → v2 체크리스트](v2.md)

이어서 v3 → v4 → v5 를 순서대로 적용한다 ([지름길](index.md#fast-path-to-a-checklist)).
