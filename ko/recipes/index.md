# 레시피

목적 지향적 코드 예시집. 「어떻게 동작하는가」는 [가이드](../guides/) 에 있다. 여기의 모든 것은 v5 어휘 (`flags` / `bloxdLit()` / `fogAlpha` / `bloxdSeconds()`) 로 이식되었고, 6베리언트 (strict × terrain / liquid / model) 를 통과하도록 가드되어 있다.

## 구성

| 페이지 | 내용 |
|---|---|
| [컬러 레시피](colors.md) | 틴트, 채도, 색 온도, 세피아, 고도 그라디언트 |
| [라이팅 레시피](lighting.md) | S자 곡선, 커스텀 포그, 밤, 동굴, 노을 |
| [이미션 레시피](emission.md) | 맥동하는 불빛, 빛나는 광석, 반딧불 |
| [좌표 레시피](coordinates.md) | 월드/블록 좌표, 체커, 해시, 시선 벡터 |
| [애니메이션 레시피](animation.md) | 낮밤 사이클, 흔들림, 오로라 |

| [리얼화 레시피](realism.md) | 난색×냉색, 스페큘러, ACES, 투영 그림자 |
