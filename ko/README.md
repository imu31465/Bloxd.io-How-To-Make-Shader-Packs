# Bloxd.io 셰이더 팩 개발 문서

Bloxd.io WebGPU 렌더러용 셰이더 팩의 제작·구현·검증·배포 방법부터 API 명세와 엔진 내부 분석까지 정리한 비공식 문서입니다.

## 현재 사양

- 현재 API: **5** (`pack.json`에 `apiVersion: 5` 선언 필수)
- 대상: WebGPU 렌더러
- 셰이더 훅: 9개 (Terrain / Liquid / Model × Vertex / Surface / Light)

셰이더 팩이 처음이라면 [시작하기](getting-started/)부터, API를 찾는다면 [API 레퍼런스](api/)부터 시작하세요.

> 이 문서는 게임 개발사의 공식 자료가 아닙니다. 엔진 내부는 구현 세부 사항이며 업데이트에 따라 바뀔 수 있습니다. 지원되는 동작은 API 레퍼런스를 확인하세요.
>
> 이 문서는 AI의 도움을 받아 작성했습니다. 엔진 구현은 업데이트에 따라 바뀔 수 있으므로 실제 게임 동작을 확인하세요.
>
> 셰이더 팩은 WGSL 코드만 사용하며 JavaScript를 실행하거나 네트워크 요청을 보내지 않습니다.

## 문서 구성

- **[시작하기](getting-started/)** — 개요, 퀵 스타트, 팩 구조, pack.json, 9개 훅, 베리언트, 검증, 배포
- **[API 레퍼런스](api/)** — v5 체계적 사양: 훅, 플래그, 입출력 구조체, 전체 함수, 라이팅, 텍스처 API, 상수, 전처리기, 제한, 호환성, 1,017개의 텍스처 식별자를 담은 카탈로그.
- **[가이드](guides/)** — 라이팅의 구조, 그림자, 물, 밤, 모델 렌더링, 퍼포먼스, 사실적인 표현 개념.
- **[레시피](recipes/)** — 목적별 코드 예시: 컬러, 라이팅, 이미션, 좌표, 애니메이션, 액체, 정점, 수학, 사실적인 표현, 모델 셰이더, 인챈트 효과.
- **[문제 해결](troubleshooting/)** — 증상 기반 오류 해결: 로드, API 버전, 컴파일, 검증, 베리언트, 외관, 텍스처, 라이팅, 모델, 퍼포먼스.
- **[엔진 내부](internals/)** — 렌더링 파이프라인, 훅 호출, 엔진 헤더, 검증·컴파일 내부, 예약 식별자, 라이팅/포그 내부, 텍스처 샘플링·레지스트리, 모델 렌더링, 실측 데이터.
- **[버전 히스토리](history/)** — v1부터 v5까지: 버전별 변경, 이주 절차, 폐지된 API.

## 검증 상태 라벨

각 페이지에는 다루는 API 버전과 내용의 확인 상태가 기재되어 있습니다.

| 라벨 | 의미 |
|---|---|
| Verified | 실제 게임에서 확인됨 |
| Analyzed | 내부 구현 분석으로 확인됨 |
| Partially Verified | 일부만 확인됨 |
| Experimental | 실험적·미확정 |
| Historical | 과거 버전 자료 |

엔진에서 추출한 데이터(헤더, 레지스트리, 측정값)는 [엔진 내부](internals/)에 정리되어 있으며, 분석 방법과 기록은 [분석 로그](internals/research-log.md)에서 확인할 수 있습니다.
