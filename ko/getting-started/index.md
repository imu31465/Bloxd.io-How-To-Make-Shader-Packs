# 시작하기

이 가이드는 첫 셰이더 팩을 만드는 과정을 기초부터 테스트와 배포까지 순서대로 안내합니다. 현재 API v5를 기준으로 설명하며, 이전 버전에서의 마이그레이션은 [버전 히스토리](../history/)를 참고하세요.

## 안내 순서

1. [개요와 전제](overview.md) — 셰이더 팩으로 되는 것과 안 되는 것
2. [요구 사항](requirements.md) — 브라우저와 렌더러 요구
3. [퀵 스타트](quick-start.md) — 5분 만에 첫 팩
4. [팩 구조](pack-structure.md) — zip 내용물과 크기 제한
5. [pack.json](manifest.md) — 매니페스트의 모든 필드
6. [셰이더 훅](hooks.md) — 9개 훅의 역할
7. [베리언트](variants.md) — 6개 베리언트와 매크로 가드
8. [검증](validation.md) — 3단계 로드 검사와 실기기 테스트
9. [배포](distribution.md) — zipping 과 릴리스 위생


전체 사양이 필요하면 [API 레퍼런스](../api/) 로, 완성품 효과는 [레시피](../recipes/) 로 계속하라.
