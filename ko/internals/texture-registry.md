# 텍스처 레지스트리 내부

> 대상 API: 5 · 상태: Analyzed

이 페이지는 텍스처 이름이 어떻게 해석되고 셰이더 팩에서 참조되는지 설명한다. 팩 작성자가 사용할 수 있는 이름은 [텍스처 카탈로그](../api/texture-catalog.md)를 참조한다.

## 이름 상수

팩에서는 `bloxdTextureId*` 형식의 이름 상수를 사용한다. 팩 로딩 시 텍스처 이름이 레지스트리에 맞춰 해석되므로 숫자 ID를 직접 고정할 필요가 없다.

**이름을 API로 취급하고 숫자 ID에 의존하지 않는다.** 아틀라스 배치와 ID는 변경될 수 있는 구현 세부 사항이다.

## 애니메이션 텍스처

애니메이션 텍스처는 프레임 번호가 아니라 해당 계열의 기본 이름으로 참조한다. 샘플링할 때 엔진이 현재 프레임을 선택하므로 팩이 프레임을 직접 전환할 필요는 없다.

프레임 표기는 일반적인 용도의 별도 이름 상수가 아니다. 카탈로그에 있는 기본 이름을 사용한다.

## 회전 텍스처

면별 회전은 텍스처 샘플링 과정에서 적용된다. 팩이 내부의 사전 회전 아틀라스 슬롯을 직접 선택할 필요는 없다.

## 샘플링 참고

- [텍스처 카탈로그](../api/texture-catalog.md)에서 이름을 선택한다.
- 숫자 ID나 내부 아틀라스 배치에 의존하지 않는다.
- 애니메이션과 면 회전은 일반적으로 엔진의 샘플링 처리에 맡긴다.
