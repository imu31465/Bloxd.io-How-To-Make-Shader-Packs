# Bloxd.io シェーダーパック開発ドキュメント

Bloxd.io の WebGPU レンダラー向けシェーダーパックについて、作成・実装・検証・配布方法から、API仕様やエンジン内部の技術資料までをまとめた非公式ドキュメントです。

## 現行仕様

- 現行API: **5** (`pack.json` の `apiVersion: 5` が必須)
- 対象: WebGPU レンダラー
- 最終確認: 2026-11-05
- 対象ビルド: `v98qt8.main.62d8d238.js` (本番+preprod、2026-11-08 確認、バイト同一バンドル、md5 `7458fd47ff88331d9f451d1456ff48ac` — レジストリ・ヘッダー・フック・制限を再計測)
- 対応シェーダーフック: 9種 (Terrain / Liquid / Model × Vertex / Surface / Light)

新しくシェーダーパックを作成する場合は [はじめに](getting-started/) から、API仕様を調べる場合は [APIリファレンス](api/) から読み進めてください。

> このドキュメントはゲーム開発元による公式資料ではありません。エンジン内部の仕様はアップデートによって変更される場合があります。各ページに記載された対象ビルドと検証状況を確認してください。
>
> 本書はAIの支援を受けて作成されており、内容の正確性は保証されない。実際のゲーム動作で確認すること。レシピは読み込み画面・実機コンパイルで継続検証すること。
>
> シェーダーパック機能自体はゲーム内 UI から読み込める公式機能であり、パックは純粋な WGSL (JS 実行・通信不可) のため、通常の記述で危険なことは起きない。

## ドキュメント構成

- **[はじめに](getting-started/)** — 概要、最短手順、パック構成、pack.json、9つのフック、バリアント、検証、配布。最初のパックを完成させられる一本道のチュートリアル。
- **[APIリファレンス](api/)** — 現行API v5の体系的な仕様書。フック、フラグ、入出力構造体、全関数、ライティング、テクスチャAPI、定数、プリプロセッサ、制限、互換性、911名のテクスチャカタログ。
- **[ガイド](guides/)** — ライティングの仕組み、影、水、夜間、モデルの描画、パフォーマンス、リアル化の考え方、できること・できないこと。
- **[レシピ](recipes/)** — 目的別の実装例集。色、照明、発光、座標、アニメーション、液体、頂点、数式、リアル化、モデルシェーダー、エンチャント効果。
- **[トラブルシューティング](troubleshooting/)** — 症状から探せるエラー対処集。読み込み、APIバージョン、コンパイル、検証、バリアント、視覚、テクスチャ、ライティング、モデル、パフォーマンス。
- **[エンジン内部と研究](internals/)** — レンダリングパイプライン、フック呼び出し、エンジンヘッダ、検証とコンパイル処理、予約名、ライティング/フォグ内部、テクスチャサンプリング、レジストリ、モデル描画、実測データ。
- **[バージョン履歴](history/)** — v1からv5までの各バージョンの変更内容、移行手順、廃止されたAPI。

## 検証状況の表記

各ページには対象APIバージョン・対象ビルド・最終確認日・検証状況を記載します。

| ラベル | 意味 |
|---|---|
| Verified | 実機・対象ビルドで検証済み |
| Analyzed | 内部実装を解析して確認 |
| Partially Verified | 一部のみ確認 |
| Experimental | 実験的・未確定 |
| Historical | 過去バージョンの資料 |

エンジンから抽出した生データ (ヘッダー、レジストリ、実測値) は [エンジン内部と研究](internals/) に、その元となった解析手法とログは [research-log](internals/research-log.md) に追跡できます。
