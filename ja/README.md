# Bloxd.io シェーダーパック開発ドキュメント

Bloxd.io の WebGPU レンダラー向けシェーダーパックについて、作成・実装・検証・配布方法から、API仕様やエンジン内部の技術資料までをまとめた非公式ドキュメントです。

## 現行仕様

- 現行API: **5** (`pack.json` の `apiVersion: 5` が必須)
- 対象: WebGPU レンダラー
- 最終確認: 2026-11-03
- 対象ビルド: `ab90qa.main.6188124c.js` (本番と preprod が同一バンドル — md5 `fc3322212d15be2445c0e8dfc9733fcc` で検証済み)
- 対応シェーダーフック: 9種 (Terrain / Liquid / Model × Vertex / Surface / Light)

新しくシェーダーパックを作成する場合は [Getting Started](getting-started/) から、API仕様を調べる場合は [API Reference](api/) から読み進めてください。

> このドキュメントはゲーム開発元による公式資料ではありません。エンジン内部の仕様はアップデートによって変更される場合があります。各ページに記載された対象ビルドと検証状況を確認してください。
>
> 本書はAIの支援を受けて作成されており、内容の正確性は保証されない。実際のゲーム動作で確認すること。レシピは読み込み画面・実機コンパイルで継続検証すること。
>
> シェーダーパック機能自体はゲーム内 UI から読み込める公式機能であり、パックは純粋な WGSL (JS 実行・通信不可) のため、通常の記述で危険なことは起きない。

## ドキュメント構成

- **[Getting Started](getting-started/)** — 概要、最短手順、パック構成、pack.json、9つのフック、バリアント、検証、配布。最初のパックを完成させられる一本道のチュートリアル。
- **[API Reference](api/)** — 現行API v5の体系的な仕様書。フック、フラグ、入出力構造体、全関数、ライティング、テクスチャAPI、定数、プリプロセッサ、制限、互換性、896名のテクスチャカタログ。
- **[Guides](guides/)** — ライティングの仕組み、影、水、夜間、モデルの描画、パフォーマンス、リアル化の考え方。
- **[Recipes](recipes/)** — 目的別の実装例集。色、照明、発光、座標、アニメーション、液体、頂点、数式、リアル系、モデルシェーダー、エンチャント効果。
- **[Troubleshooting](troubleshooting/)** — 症状から探せるエラー対処集。読み込み、APIバージョン、コンパイル、検証、バリアント、視覚、テクスチャ、ライティング、モデル、パフォーマンス。
- **[Engine Internals & Research](internals/)** — レンダリングパイプライン、フック呼び出し、エンジンヘッダ、検証とコンパイル処理、予約名、ライティング/フォグ内部、テクスチャサンプリング、レジストリ、モデル描画、実測データ。
- **[Version History](history/)** — v1からv5までの各バージョンの変更内容、移行手順、廃止されたAPI。

| ラベル | 意味 |
