# バージョン履歴

> 種別: Historical · API v1〜v5の移行資料

API v1からv5までの変更内容、移行手順、廃止されたAPIをまとめています。ここでは各バージョンの機能と移行経路を説明し、ビルド番号や確認日時は掲載しません。

## バージョン一覧

| バージョン | 移行ガイド | 主な変更 |
|---|---|---|
| v1 | [v1](v1.md) | シェーダーパック機構の初期API |
| v2 | [v2](v2.md) | 識別子の改名、`blockId`、シーン深度API |
| v3 | [v3](v3.md) | `blockFlags`、`bloxdPi` / `bloxdTau`、液体フック |
| v4 | [v4](v4.md) | テクスチャAPI、strictゲームの制約 |
| **v5** | [v5](v5.md) | **現行** — `BloxdFlags`、Modelフック、ライティングAPI、影API |

## 各バージョンの扱い

現行ゲームが受け付けるのは `apiVersion: 5` のパックだけです。旧バージョンのパックは、そのままでは読み込めません。複数のバージョンをまたいで移行する場合は、古いバージョンから順に各ガイドを適用してください。

## 移行チェックリストへの早道

- v4パック → [v5移行ガイド](v5.md)
- v3パック → [v4](v4.md) → [v5](v5.md)
- v2パック → [v3](v3.md) → [v4](v4.md) → [v5](v5.md)
- v1パック → [v2](v2.md) → [v3](v3.md) → [v4](v4.md) → [v5](v5.md)

現行APIの仕様は[APIリファレンス](../api/)を参照してください。
