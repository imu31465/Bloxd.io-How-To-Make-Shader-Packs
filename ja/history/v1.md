# API v1

> 検証状況: **Historical** — シェーダーパック機構の初出期の記録。v1 パックの全ては現行ゲームで読み込み拒否されます。

v1 はシェーダーパック機構の最初期の API です。v2 で識別子が全面改名されたため ([v2 移行ガイド](v2.md) §32 の対応表)、v1 の語彙を知っている主な価値は**古い配布パックや古いコミュニティガイドを読むとき**です。

## v1 の語彙 (v2 で改名されたもの)

| v1 | v2 以降 |
|---|---|
| `bloxdTime()` | `bloxdTime()` (v3 で `bloxdSeconds()` へ) |
| `bloxdOriginOffset()` | 同名 (v3 で `bloxdRenderOffset()` へ) |
| `bloxdFaceBlock(position, normal)` | 同名 (v3 で削除) |
| `fogFactor` | `fogVisibility` (v5 で `fogAlpha` へ・意味反転) |
| `engineColour` | 同名 (v5 で削除 — `litColour` と `bloxdLitColour()` に再構成) |
| — | `blockId` (v2 で追加、v3 で `blockFlags` へ) |

フックは terrain / liquid × vertex / surface の**6フック**で、light フックは存在しませんでした (v5 のデフォルトテンプレートで同梱されるまで、light フックは文書からコピーするものだった)。ブロックの識別手段はテクスチャ色からの推定のみで、`blockId` / `blockFlags` / `flags` はまだありませんでした。

## v1 → v2 の移行

識別子の全面改名を含むため、機械的な変換では済みません。手順は [v2 移行ガイド](v2.md) を最初から読み直してください:

1. [§31 v1 パックの運命](v2.md) — 読み込み拒否の挙動
2. [§32 識別子の全面改名 (対応表)](v2.md) — リネーム表
3. [§33 削除フィールドの移植先](v2.md)
4. [§37 v1 → v2 移行チェックリスト](v2.md)

そこからさらに v3 → v4 → v5 と段階適用します ([年表](index.md#移行チェックリストへの早道))。
