# デバッグのコツ

> 対象API: 5 · 対象ビルド: `ab90qa` (2026-11-03 本番確認) · 検証状況: Verified (v5 移植済み — 動作は同一ビルドで実機確認を推奨)

見た目の問題を症状から原因へたどるガイド。エラー (検証・コンパイル) については [トラブルシューティング](../troubleshooting/) を参照。


- 洞窟が明るすぎる → `skyLight` の非線形カーブが不足している ([洞窟の暗化](../recipes/lighting.md) / [非線形暗化](../recipes/realism.md))
- 木の下・屋根の下を `pow(skyLight, γ)` で強調しても暗くならない → `l.skyLight` はリフト後の値 (10章)。[投影風シャドウ](../recipes/realism.md) の逆変換 + しきい値カットに切り替える
- 影の面積・濃さを調整したい → [投影風シャドウ](../recipes/realism.md) の調整ガイドを参照 (面積=しきい値 `shTh` / 縁=`shSoft` / 芯の暗さ=最低環境光と空散乱光の 2 点シフト)
- 昼間が白飛びする → ACES 前の露出を下げる
- 夜が暗すぎる → 最小環境光を確保する。`bloxdSunDirection()` がゼロのときは真の月方向が不明なため、青い環境光などの擬似表現を用いる
- 夜なのに照らされた面だけ明るすぎる → 影の色だけを暗くせず、エンジンの完成色  (既定の出力) 全体にも夜間減衰をかける。局所光を残す場合は `blockLight` / `heldLight` を使って減衰を弱める ([夜間表現の設計](night.md))
- 遠景が霞みすぎる → 大気減衰の係数を下げる
- 松明の周りがオレンジだらけ → 暖色ブレンドの比率を下げる (素の色つき光を残す)
- ブロックがほとんど真っ白になる → light フック出力の合計が 1.0 を超過している (出力の先にクランプは存在しない)。最後に `clamp(col, vec3f(0.0), vec3f(1.0))` を挿入する
- 加算が無いのに白い → fog の除算による un-fog 逆算が原因。un-fog を外し、再構築する場合は `s.colour` を起点とし、フォグは最後に一度だけ `mix` で適用
- 発光ブロックが光らない → 再構築系で emission の再加算漏れ。`+ s.emission * (1.0 - l.fogAlpha)` を追加する
