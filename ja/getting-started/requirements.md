# 動作環境

> 対象API: 5 · 検証状況: Verified

## ブラウザ

シェーダーパックは WebGPU レンダラー専用です。WebGPU に対応したブラウザが必要です:

- Chromium 系 (Chrome / Edge / Opera 等) — デスクトップで安定
- Safari 17+ / Firefox (WebGPU 対応状況は時期により異なる)
- **モバイル**: iOS / Android では WebGPU 対応が限定される場合があります。パック配布時に注意書きを添えると親切です

パック導入中はゲーム設定の WebGPU レンダラーが強制的にオンになります。

## パックの開発環境

特別なツールは不要ですが、あると便利なもの:

- テキストエディタ (WGSL のシンタックスハイライトに対応したものだとなおよし)
- zip 圧縮ツール (配布時)。開発中はフォルダ読み込みが使えます (デスクトップ版ブラウザのみ)
- ブラウザの開発者ツール — コンパイルエラーの詳細はゲーム内 UI に表示されますが、開発者ツールのコンソールにも出ます

## 実機検証の環境

配布前に以下の組み合わせで確認することを推奨します ([検証と動作確認](validation.md)):

1. allow モードのゲーム (頂点移動を使うパックは必須)
2. strict モードのゲーム (大多数はこちら)
3. ページ再読み込み後の再検証 (保存パックの再検証は自動で走る)

## URL パラメータの注意

URLパラメータや localStorage にレンダラーオーバーライドが残っているとパックの起動が拒否されるため、それらを除去してから再読み込みしてください。
