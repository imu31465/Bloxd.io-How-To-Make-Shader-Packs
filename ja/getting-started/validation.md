# 検証と動作確認

## 読み込み時の3段階検証

パックを読み込むと、ゲーム側で次の順に検査されます:

1. **ローダー制限チェック** — サイズ・形式・`pack.json` の妥当性 ([パックの構成](pack-structure.md) の上限)
2. **静的コンパイル (アナライザ)** — 全6バリアントの構文・型・予約名・strict 契約の検証
3. **ブラウザでの WebGPU を用いた実コンパイル検証** — 静的検証は型チェックが不完全なため、この段階でしか失敗しない記述が存在する

エラーメッセージの読み方と対処法は [トラブルシューティング](../troubleshooting/) の各ページに症状別にまとめてあります。

## 手順

1. 設定 → Shader Pack から zip またはフォルダを読み込む
2. ステータスを確認する。選択直後は「Ready. Reload the page to use it.」が表示され、**ページ再読み込み後**に「Ready to use」であれば成功
3. 「Saved, but it won't run until you fix these errors...」の場合は、エラー一覧 (ファイル:行 + バリアント) を修正して再読み込みする
4. まず制限の緩いゲームで確認し、次に strict モードのゲーム (大多数はこちら) で確認する。頂点移動を使用する場合は、allow 指定のあるゲームでのみ動作する
5. パックの差し替えは同じ画面から読み込み直せるが、反映にはページ再読み込みが必要
6. 削除は Remove Pack で行う。ゲーム更新後の再検証は、ページ読み込み時に自動で行われる (エンジンのヘッダーやテクスチャレジストリが変わると保存パックは「要再チェック」になり、再検証される)
