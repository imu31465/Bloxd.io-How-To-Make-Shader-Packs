# 配布

> 対象API: 5 · 検証状況: Verified

## 配布形態

1. `pack.json` をルートに配置した zip に圧縮する ([パックの構成](pack-structure.md) のサイズ上限内であること)
2. zip の中で `pack.json` が直下に来ることを確認する (ルートフォルダ1階層は自動で剥がされる)
3. `pack.json` の `name` / `author` を配布用に整える

## 配布前の最終チェック

- [ ] `apiVersion: 5` (数値)
- [ ] 6バリアントすべてで検証が通る (読み込み画面のエラー一覧が空)
- [ ] allow ゲームと strict ゲームの両方で目視確認した
- [ ] 頂点移動・`discard` を使うパックは allow ゲーム限定と明記した
- [ ] 動作確認済みのゲーム名と対象時期 (ビルドは変わる) を README 等に書いた

## 配布後の運用

- プレイヤー機器に保存されたパックは、ゲーム更新でエンジンのヘッダーやテクスチャレジストリが変わると「要再チェック」になり、ページ読み込み時に自動で再検証される
- **旧バージョン (v1〜v4) として配布したパックは、v5 環境では暗黙に不活性化**される ([pack.json](manifest.md) の節を参照)。プレイヤーには設定タブのステータス行で理由が表示されるだけなので、バージョンを上げた新版の再配布と案内を
- API が更新されたら [バージョン履歴](../history/) の移行手順でパックを更新し、バージョンを上げて再配布する
