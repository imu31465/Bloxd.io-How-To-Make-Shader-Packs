# Troubleshooting

エラーと見た目の問題を**症状から探せる**構造です。各ページは「症状 → 原因 → 確認方法 → 解決方法 → 再発防止」の順で説明します。

## 症状インデックス

まず起きている症状に近い行を探してください。

| 症状 | ページ |
|---|---|
| パックが読み込めない / zip・pack.json のエラー | [読み込みエラー](loading.md) |
| `apiVersion` 関連のメッセージ / 旧パックが動かない | [APIバージョンエラー](api-version.md) |
| コンパイルが通らない / `must be declared as` / WGSL 構文エラー | [コンパイルエラー](compilation.md) |
| 検証エラー (予約名・strict 契約・`reaches`・直接構築) | [検証エラー](validation.md) |
| 特定バリアントだけで失敗する / strict ゲームで外される | [バリアント固有の問題](variants.md) |
| 見た目がおかしい (白濁・影が出ない・夜が変) | [視覚の問題](visual.md) |
| テクスチャ名のエラー / `did you mean` | [テクスチャの問題](textures.md) |
| 明るさ・影・フォグの不具合 | [ライティングの問題](lighting.md) |
| モデル・エンティティ・エンチャントの不具合 | [モデルの問題](models.md) |
| 遅い / 実機チェックで外れる | [パフォーマンス](performance.md) |
| 権利・安全性・よくある質問 | [FAQ](faq.md) |

## エラーが表示される場所

1. **設定 → Shader Pack のステータス行** — ローダー段階のエラー (ID は `shaderPack:load*`)
2. **読み込み画面のエラー一覧** — 検証・コンパイル段階 (ファイル:行 + バリアントつき)
3. **ブラウザ開発者ツールのコンソール** — 実行時・第2段階 (ブラウザ WGSL コンパイラ) のエラー

読み込み時の3段階検証 (ローダー制限 → 静的検証 → ブラウザ実コンパイル) の詳細は [Getting Started: 検証](../getting-started/validation.md) を参照。
