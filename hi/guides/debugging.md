# दोषमार्जन युक्तियाँ

> लक्ष्य API: 5 · लक्ष्य बिल्ड: `xkg8x` (2026-11-04, production) · स्थिति: Verified (वर्तमान API पर पोर्ट किया गया — डिवाइस पर पुनः जाँच की सिफ़ारिश)
- गुफ़ाएँ बहुत उजली → `skyLight` का अरैखिक वक्र छूटा हुआ (R2 गुफ़ा रेसिपी / R9.9)
- फटे हुए दिन → ACES-पूर्व एक्सपोज़र घटाएँ
- रातें देखे न जाने जितनी अंधेरी → न्यूनतम परिवेश सुनिश्चित करें (रात का `skyLightColour` प्राकल्पना से ही लगभग काला है)
- दूरी पर अति-धुंध → वायुमंडलीय गुणांक घटाएँ
- मशाल के आसपास सब नारंगी → उष्ण मिश्रण अनुपात घटाएँ (थोड़ा कच्चा रंजित प्रकाश रखें)
- ब्लॉक लगभग पूरे सफ़ेद → लाइट हुक के निर्गम का योग 1.0 पार कर जाता है (अनुप्रवाह कोई clamp नहीं)। अंत में `clamp(col, vec3f(0.0), vec3f(1.0))` लगाएँ
- योग बिना ही सफ़ेद → फ़ॉग-विभाजन से un-fog व्युत्क्रमण के कारण। un-fog हटाएँ; `s.colour` से पुनर्निर्माण करें और फ़ॉग अंत में एक बार `mix` करें
- उत्सर्जक ब्लॉक नहीं चमकते → पुनर्निर्माण रेसिपियों में emission का दोबारा योग छूटा हुआ। `+ s.emission * (1.0 - l.fogAlpha)` जोड़ें
- रात केवल प्रकाशित फलकों पर ग़लत दिखे → केवल छाया रंग गहरे न करें; रात में इंजन के पूरे पूर्ण रंग (`engineColour`) को क्षय करें। स्थानीय दीये रखने के लिए `blockLight` / `heldLight` से क्षय कमज़ोर करें ([रात के रूप डिज़ाइन करना](night.md))
- `pow(skyLight, γ)` से छाया गहरी न होती हो → `l.skyLight` लिफ्ट-बाद का मान है (अध्याय 10)। R9.12 व्युत्क्रम + देहली कट पर जाएँ
- छाया क्षेत्रफल/सघनता समायोजित करनी हो → R9.12 समायोजन मार्गदर्शिका देखें (क्षेत्रफल = देहली `shTh` / किनारा = `shSoft` / क्रोड अंधेरा = न्यूनतम परिवेश व आकाश-प्रकीर्णन का दो-बिंदु स्थानांतरण)
