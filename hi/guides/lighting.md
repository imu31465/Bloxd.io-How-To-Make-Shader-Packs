# प्रकाश कैसे काम करता है

> लक्ष्य API: 5 · लक्ष्य बिल्ड: `v98qt8` (2026-11-08, प्रोडक्शन और preprod) · स्थिति: Verified (वर्तमान API पर पोर्ट किया गया — डिवाइस पर पुनः जाँच की सिफ़ारिश)
इंजन का डिफ़ॉल्ट प्रकाश "केवल गुणन" है — कोई स्पेक्युलर, फ्रेनेल, उष्ण/शीत पृथक्करण या अर्धगोल परिवेश मौजूद नहीं है। निम्नलिखित चीज़ें दोबारा बनाई जा सकती हैं:

| सुविधा | डिफ़ॉल्ट | पैक में बनाई जा सकती है? |
|---|---|---|
| डिफ़्यूज़ (Lambert) | केवल दिशात्मक लाइटों का अदिश योग | ◎ `bloxdSunDirection()` से स्वनिर्मित (wrapped falloff आदि) |
| स्पेक्युलर | कुछ नहीं | ◎ Blinn-Phong (R9.2) |
| फ्रेनेल | कुछ नहीं | ◎ Schlick सन्निकटन (R9.3) |
| उष्ण-मशाल / शीत-आकाश पृथक्करण | अवर्णित | ◎ (R9.1) |
| अर्धगोल परिवेश | केवल दिशाहीन | ◎ ऊपर आकाश / नीचे भूमि (R9.4) |
| तान मानचित्रण | कुछ नहीं (केवल clamp) | ◎ ACES फ़िल्मिक (R9.5) |
| वायुमंडलीय परिप्रेक्ष्य | केवल फ़ॉग (रंग प्रतिस्थापन) | ◎ दूरी से विसंतृप्ति (R9.6) |
| सतह का विवरण | केवल टेक्सचर विभेदन | △ प्रक्रियात्मक हैश-शोर सूक्ष्म-उभार (R9.8) |
| शीर्ष तरंगें (जल) | कुछ नहीं (समतल) | ◎ केवल allow (R7) |
| तरंग अभिलंब / सूर्य की चमक | कुछ नहीं | ◎ (R9.7) |
| रात्रि चंद्रप्रकाश | केवल आकाश का रंग गहरा पड़ता है | △ चंद्र दिशा का कोई इनपुट नहीं, इसलिए केवल छद्म रूप (R2 का नीला परिवेश / R9.11 की विसंतृप्ति) |
| छायाएँ (आकाश-अवरोध) | केवल `mix(ambient, sky, skyLight)` से सौम्य मिश्रण | ◎ लिफ्ट व्युत्क्रम + देहली कट + सूर्य गेट (R9.12)। पेड़ की छाया और छत के नीचे के हिस्से साफ़ गिरते हैं और ब्लॉक संपादनों का पालन वास्तविक समय में करते हैं |
