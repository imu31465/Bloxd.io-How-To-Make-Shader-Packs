# सूर्य और चंद्र

> लक्ष्य API: 5 · प्रकार: तकनीकी संदर्भ

`bloxdSunDirection()` सूर्य की दिशा वाला एक बफ़र पढ़ता है, जिसे केवल स्काईबॉक्स का प्रकार बदलने पर अपडेट किया जाता है। निर्णायक शर्त यह नहीं है कि आकाश में सूर्य दिखाई देता है या नहीं, बल्कि **स्काईबॉक्स का प्रकार `earth` है या नहीं**।

| स्काईबॉक्स | `bloxdSunDirection()` |
|---|---|
| `default` (प्रोसीज़रल आकाश) | शून्य से अलग (डिफ़ॉल्ट मान नीचे दिए गए हैं) |
| `gloomy` / `interstellar` / `space_*` (क्यूब टेक्सचर) | **सदा (0,0,0)** |

जब `bloxdSunDirection()` शून्य से अलग वेक्टर लौटाता है, तो चंद्रमा की दिशा `-bloxdSunDirection()` होती है (इंजन उसे सूर्य के ठीक विपरीत रखता है)। यदि यह शून्य लौटाता है, तो इस फ़ंक्शन से चंद्रमा की वास्तविक दिशा ज्ञात नहीं की जा सकती। रात का निर्धारण सूर्य की ऊँचाई से होता है: जब `bloxdSunDirection().y < 0` (सूर्य क्षितिज से नीचे) हो, तब चंद्रमा क्षितिज के ऊपर होता है। डिफ़ॉल्ट दुनियाओं में सूर्य स्थिर रहता है, इसलिए चंद्रमा भी स्थिर रहता है; वह केवल दिन-रात का चक्र लागू करने वाली दुनियाओं में चलता है।

डिफ़ॉल्ट-दुनिया की सूर्य दिशा लगभग `(-0.56, 0.81, -0.18)` है (inclination = −0.2 / azimuth = 0.55 से गिनी गई इकाई सदिश, स्थिर)। पैक की जाँच करते समय इस मान से हाइलाइट की दिशा का अनुमान लगाया जा सकता है।

दिन-रात चक्र इंजन में अंतर्निहित नहीं है — inclination एक स्थिर संख्या है, और चलता दिन-रात रखने वाली दुनियाएँ उसे गेम स्वयं अपडेट करता है। `bloxdSunDirection()` हर अपडेट का अनुसरण करता है।

Terrain को रोशन करने वाले केवल दो दिशात्मक प्रकाश-स्रोत हैं, जिन्हें scene शुरू होते समय बनाया जाता है। **उनकी दिशा और तीव्रता दिन-रात एक जैसी रहती है।** यानी terrain की चमक समय के साथ नहीं बदलती; दिन और रात का दृश्य केवल स्काईबॉक्स और `bloxdSunDirection()` से तय होता है। इसलिए रात में terrain को गहरा करने वाले पैकों को `bloxdSunDirection()` के आधार पर समय का अनुमान स्वयं लगाना होगा, जैसे [रात का रूप डिज़ाइन करना](../guides/night.md) में दी गई `sunPresent` तकनीक।

## R-A. चाँदनी

चंद्रमा क्षितिज के ऊपर होने पर ही नीली-सफ़ेद Lambert रोशनी और हल्का specular प्रतिबिंब जोड़ा जाता है। स्थिर सूर्य वाली डिफ़ॉल्ट दुनियाओं में `moonUp` का मान 0 रहता है, इसलिए वहाँ कोई प्रभाव नहीं दिखता। **चाँदनी का यह प्रभाव केवल उन्हीं दुनियाओं में सक्रिय होता है जिनमें दिन-रात का चक्र लागू किया गया है।**

```wgsl
fn bloxdTerrainLight(s: BloxdSurface, l: BloxdLightIn) -> BloxdLight {
    var out = bloxdDefaultLight(s, l);
    if (bloxdLit()) {
        // चंद्रमा सूर्य के विपरीत तभी होता है, जब सूर्य-दिशा वेक्टर शून्य न हो。
        let moonDir = -bloxdSunDirection();
        let moonUp  = smoothstep(0.0, 0.15, moonDir.y);
        if (moonUp > 0.0) {
            let n     = normalize(l.normal);
            let diff  = max(0.0, dot(n, moonDir));
            let view  = normalize(bloxdEyePosition() - l.position);
            let halfV = normalize(moonDir + view);
            let spec  = pow(max(0.0, dot(n, halfV)), 48.0) * 0.25;
            out.colour += vec3f(0.10, 0.14, 0.24) * (diff * 0.6 + spec) * moonUp;
        }
    }
    return out;
}
```
