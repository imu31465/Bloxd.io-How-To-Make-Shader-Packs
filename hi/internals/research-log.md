# अनुसंधान लॉग

> स्थिति: Analyzed

यह पृष्ठ गेम के कार्यान्वयन से जुड़ी तकनीकी टिप्पणियों को समझने का तरीका बताता है। आंतरिक व्यवहार सार्वजनिक API अनुबंध नहीं है और गेम अपडेट के साथ बदल सकता है।

## अनुसंधान सिद्धांत

1. **दिखाई देने वाले व्यवहार की जाँच करें** — दस्तावेज़ को इन-गेम validation और runtime व्यवहार से मिलाएँ।
2. **कार्यान्वयन और API को अलग रखें** — shader packs के लिए उपलब्ध सुविधाओं और केवल इंजन के अंदर उपयोग होने वाले तरीकों में अंतर रखें।
3. **निष्कर्ष का आधार बताएँ** — किसी मान या व्यवहार के पीछे इंजन की कौन-सी प्रक्रिया है, यह स्पष्ट करें।
4. **अनुमान को तथ्य न बताएँ** — देखे गए तथ्य, उनकी व्याख्या और अनसुलझे प्रश्न अलग रखें।
5. **जाँच के समय को रिलीज़ का समय न मानें** — जाँच के दौरान किया गया सत्यापन यह साबित नहीं करता कि कोई सुविधा कब वितरित हुई।
