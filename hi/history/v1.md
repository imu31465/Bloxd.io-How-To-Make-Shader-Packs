# API v1

> स्थिति: **Historical** — शेडर-पैक तंत्र का पहला दौर। हर v1 पैक मौजूदा गेम द्वारा अस्वीकृत होता है।

v1 पहला शेडर-पैक API था। v2 ने पहचानकर्ताओं का पूर्ण पुनर्नामकरण कर दिया ([v2 गाइड](v2.md) की §32 तालिका), इसलिए v1 शब्दावली जानने का मुख्य मूल्य **पुराने वितरण और पुरानी सामुदायिक गाइड पढ़ना** है।

## v1 शब्दावली (v2 में पुनर्नामकृत)

| v1 | v2 और आगे |
|---|---|
| `bloxdTime()` | वही (v3 में `bloxdSeconds()` बना) |
| `bloxdOriginOffset()` | वही (v3 में `bloxdRenderOffset()` बना) |
| `bloxdFaceBlock(position, normal)` | वही (v3 में हटाया गया) |
| `fogFactor` | `fogVisibility` (v5 में `fogAlpha` बना, अर्थ उलट गया) |
| `engineColour` | वही (v5 में हटाया गया — `litColour` और `bloxdLitColour()` में पुनर्गठित) |
| — | `blockId` (v2 में जोड़ा गया, v3 में `blockFlags` बना) |

हुक terrain / liquid × vertex / surface थे — **6 हुक**, कोई लाइट हुक नहीं (लाइट हुक v5 में जाकर डिफ़ॉल्ट टेम्पलेट का हिस्सा बए)। खंड-पहचान केवल टेक्सचर-रंग से अनुमान लगाना थी; `blockId` / `blockFlags` / `flags` तब अस्तित्व में ही नहीं थे।

पूर्ण पुनर्नामकरण का अर्थ है कि यह कोई यांत्रिक रूपांतरण नहीं है। [v2 माइग्रेशन गाइड](v2.md) को ऊपर से पढ़ें:

1. [§31 v1 पैकों का भाग्य](v2.md)
2. [§32 पहचानकर्ता पुनर्नामकरण (तालिका)](v2.md)
3. [§33 हटाए गए फ़ील्ड कहाँ चले गए](v2.md)
4. [§37 v1 → v2 चेकलिस्ट](v2.md)

फिर v3 → v4 → v5 क्रम में लागू करें ([फ़ास्ट पथ](index.md#चकलसट-तक-फसट-पथ))।
