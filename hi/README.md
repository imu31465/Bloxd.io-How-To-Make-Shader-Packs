# Bloxd.io शेडर पैक दस्तावेज़ीकरण

Bloxd.io के WebGPU रेंडरर के लिए शेडर पैक पर एक अनौपचारिक गाइड — निर्माण, कार्यान्वयन, सत्यापन और वितरण से लेकर API विनिर्देश और इंजन-इंटर्नल शोध तक।

## वर्तमान विनिर्देश

- वर्तमान API: **5** (`pack.json` में `apiVersion: 5` घोषित करना अनिवार्य है)
- लक्ष्य: WebGPU रेंडरर
- अंतिम सत्यापन: 2026-11-03
- लक्ष्य बिल्ड: `ab90qa.main.6188124c.js` (प्रोडक्शन और प्रीप्रोड एक ही बंडल चलाते हैं — md5 `fc3322212d15be2445c0e8dfc9733fcc` से सत्यापित)
- शेडर हुक: 9 (Terrain / Liquid / Model × Vertex / Surface / Light)

शेडर पैक के लिए नए हैं? [शुरुआत कैसे करें](getting-started/) से शुरू करें। API देखना है? [API रेफ़रेंस](api/) देखें।

> यह दस्तावेज़ीकरण गेम डेवलपर्स का आधिकारिक संसाधन नहीं है। इंजन-इंटर्नल अपडेट के साथ बदल सकते हैं — हर पृष्ठ पर अंकित लक्ष्य बिल्ड और सत्यापन स्थिति देखें।
>
> यह गाइड AI सहायता से बनाया गया है; सटीकता की गारंटी नहीं है। वास्तविक इन-गेम व्यवहार से सत्यापित करें। रेसिपी को लोडर स्क्रीन और इन-गेम कंपाइलेशन के विरुद्ध सत्यापित करते रहें।
>
> शेडर पैक सुविधा स्वयं इन-गेम UI से सुलभ एक आधिकारिक सुविधा है, और पैक शुद्ध WGSL हैं (कोई JS निष्पादन नहीं, कोई नेटवर्क नहीं) — सामान्य कोड से कुछ भी खतरनाक नहीं होता।

## दस्तावेज़ीकरण संरचना

- **[शुरुआत कैसे करें](getting-started/)** — समीक्षा, त्वरित शुरुआत, पैक संरचना, pack.json, 9 हुक, वेरिएंट, सत्यापन, वितरण। आपके पहले पैक तक एक ही पटरी का ट्यूटोरियल।
- **[API रेफ़रेंस](api/)** — v5 की व्यवस्थित विनिर्देश: हुक, फ़्लैग, इनपुट/आउटपुट संरचनाएँ, सभी फ़ंक्शन, प्रकाश, टेक्सचर API, स्थिरांक, प्रीप्रोसेसर, प्रतिबंध, संगतता और 896 नामों का टेक्सचर कैटलॉग।
- **[गाइड](guides/)** — प्रकाश कैसे काम करता है, छायाएँ, जल, रात, मॉडल रेंडरिंग, प्रदर्शन, रियलिज़्म अवधारणाएँ।
- **[रेसिपी](recipes/)** — लक्ष्य-केंद्रित कोड उदाहरण: रंग, प्रकाश, उत्सर्जन, निर्देशांक, एनीमेशन, लिक्विड, वर्टेक्स, गणित, रियलिज़्म, मॉडल शेडर, एनचांट प्रभाव।
- **[समस्या निवारण](troubleshooting/)** — लक्षण-आधारित त्रुटि समाधान: लोडिंग, API संस्करण, कंपाइलेशन, सत्यापन, वेरिएंट, विज़ुअल, टेक्सचर, प्रकाश, मॉडल, प्रदर्शन।
- **[इंजन इंटर्नल्स और रिसर्च](internals/)** — रेंडरिंग पाइपलाइन, हुक इनवोकेशन, इंजन हेडर, सत्यापन व कंपाइलेशन इंटर्नल, आरक्षित पहचानकर्ता, प्रकाश/फ़ॉग इंटर्नल, टेक्सचर सैंपलिंग व रजिस्ट्री, मॉडल रेंडरिंग, मापे गए डेटा।
- **[संस्करण इतिहास](history/)** — v1 से v5 तक: प्रति संस्करण बदलाव, माइग्रेशन कदम, हटाई गई API।

## सत्यापन स्थिति लेबल

हर पृष्ठ अपनी लक्ष्य API संस्करण, बिल्ड, अंतिम-सत्यापन तिथि और स्थिति बताता है।

| स्तर | अर्थ |
|---|---|
| Verified | डिवाइस पर / लक्ष्य बिल्ड पर सत्यापित |
| Analyzed | आंतरिक कार्यान्वयन के विश्लेषण से पुष्ट |
| Partially Verified | केवल आंशिक रूप से पुष्ट |
| Experimental | प्रयोगात्मक / अनिर्णीत |
| Historical | पिछले संस्करण की सामग्री |

इंजन से निकाला गया कच्चा डेटा (हेडर, रजिस्ट्री, माप) [इंजन इंटर्नल्स और रिसर्च](internals/) में रहता है; उसके पीछे की पद्धति और लॉग [रिसर्च लॉग](internals/research-log.md) में ट्रैक होते हैं।
