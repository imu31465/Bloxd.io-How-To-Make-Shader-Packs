# Bloxd.io शेडर पैक बनाना (पूर्ण गाइड)

Bloxd.io शेडर पैक (केवल WebGPU रेंडरर) बनाने और वितरित करने की स्व-पर्याप्त गाइड।
**लाइव API अब `apiVersion: 3` है — यह 2026-10-19 को उत्पादन में जारी हुआ**, और वर्तमान खेल v1 व v2 पैकों को लोड पर अस्वीकार करता है (गलत API संस्करण का संदेश)। नीचे भाग I–VII अभी भी v2 आधार पर लिखे गए हैं और वैचारिक नींव के रूप में मान्य हैं — उन्हें v2 के रूप में पढ़ें, फिर वितरण से पहले भाग IX (`09-apiv3.md`) के परिवर्तन लागू करें। गाइड भाग-अनुसार फ़ाइलों में विभाजित है (यह README विषय-सूची है; रेसिपी संग्रह `03-recipes.md` में है)। पहले के v1 → v2 चरण हेतु भाग VIII (`08-apiv2.md`) देखें। भाग IX उत्पादन बिल्ड से पुनः प्राप्त इंजन आंतरिक विवरण भी प्रलेखित करता है (§49–§54: हुक कॉल, चार-मोड फ़ॉग फ़ंक्शन, `bloxdOpaqueBehind()` का कार्यान्वयन, blockFlags डिलीवरी पथ, और मापे गए हेडर हैश सहित सत्यापन पाइपलाइन)।

> यह अनौपचारिक गाइड है और डेवलपर्स के आधिकारिक मत का प्रतिनिधित्व नहीं करती। API बिना सूचना बदला जा सकता है।  
> अंतिम समीक्षा: 2026-10-20 (बंडल तुलना से v3 उत्पादन रोलआउट की पुष्टि; हुक कॉल, फ़ॉग, गहराई व blockFlags आंतरिक विवरण उत्पादन बिल्ड से पुनः प्राप्त — भाग IX §49–§54)। चूंकि कोई सार्वजनिक आधिकारिक WGSL API संदर्भ नहीं मिला, API विवरण और रेसिपी लोडिंग स्क्रीन व इन-गेम कंपाइल से सत्यापित करते रहें।  
> शेडर पैक सुविधा स्वयं गेम UI से लोड होने वाली आधिकारिक सुविधा है, और पैक शुद्ध WGSL हैं  
> (JS निष्पादन/नेटवर्क नहीं), इसलिए सामान्य कोड से कुछ खतरनाक नहीं होता।  
> यह गाइड AI सहायता से बनाई गई है; सटीकता की गारंटी नहीं। वास्तविक इन-गेम व्यवहार से सत्यापित करें।
