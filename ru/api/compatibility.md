# Совместимость

> Целевой API: 5 · Тип: справочник API

На этой странице описано, какие версии API шейдер-паков принимает текущая игра и как обрабатываются сохранённые паки для старых версий.

## Принимаемая версия API

Текущая игра принимает только паки, в манифесте которых указано числовое значение `5` для `apiVersion`. Строка `"5"` не принимается. Паки для API v1–v4 необходимо перенести на новую версию, прежде чем их можно будет загрузить.

## Сообщения при загрузке

- `pack.json needs "apiVersion": {{version}}.` — отсутствует ключ `apiVersion`
- `This pack is shader pack API version {{packVersion}}. Bloxd supports version {{version}}.` — указанная версия не совпадает с текущей

## Сохранённые паки старых версий

Пак, сохранённый для старой версии API, не будет работать в текущей игре. На экране настроек шейдер-паков появится сообщение о неподдерживаемой версии. Обновите пак по соответствующему руководству по миграции.

## Повторная проверка сохранённых паков

Сохранённые паки повторно проверяются при изменении заголовков, предоставляемых движком, или определений имён текстур. Проверка автоматически выполняется при загрузке игры. В коде пака обращайтесь к текстурам по именованным константам, а не по числовым ID, которые могут меняться.

## Совместимость среды выполнения

- **WebGPU:** для шейдер-паков требуется рендерер с поддержкой WebGPU.
- **Мобильные устройства:** в средах без поддержки WebGPU шейдер-паки недоступны ([Требования](../getting-started/requirements.md)).
- **Доступ к текстурам:** в конфигурациях рендерера без атласа функции `bloxdTexel` и `bloxdTextureSize` не обеспечивают обычный доступ к текстурам атласа ([API текстур](texture-api.md)).

## Поддержка версий API

| Версия API | Поддержка текущей игрой |
|---|---|
| v1 | Отклоняется при загрузке |
| v2 | Отклоняется при загрузке |
| v3 | Отклоняется при загрузке |
| v4 | Отклоняется при загрузке |
| **v5** | **Текущая** |
