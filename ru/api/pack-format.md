# Формат пака

> Целевой API: 5 · Тип: справочник API

На этой странице описаны манифест, ограничения ZIP-архива и uniform пака. Инструкции по настройке см. в разделе [Начало работы](../getting-started/manifest.md).

## pack.json

Разместите `pack.json` в корне ZIP-архива. Это должен быть JSON-объект.

```json
{
  "apiVersion": 5,
  "name": "My Pack",
  "author": "Author Name",
  "keepCircleShadows": false
}
```

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `apiVersion` | number | Да | Укажите числовое значение `5`. Строка не принимается |
| `name` | string | Да | Непустое имя после удаления пробелов по краям |
| `author` | string | Нет | Имя автора |
| `keepCircleShadows` | boolean | Нет | Значение `true` сохраняет традиционные круглые тени при использовании API теней |

## Ограничения загрузчика

| Параметр | Ограничение |
|---|---:|
| Файлы `.wgsl` на пак | 256 |
| Общий объём исходного кода `.wgsl` | 256 КБ |
| `pack.json` | 64 КБ |
| ZIP-архив | 32 МБ |
| Записи ZIP | 1 024 |

Разделённые ZIP-архивы, Zip64, зашифрованные записи и неподдерживаемые методы сжатия не поддерживаются. Сохраняйте все файлы в UTF-8 и не используйте повторяющиеся пути внутри архива.

## Uniform пака

Размер uniform пака составляет 80 байт; он привязан к `@group(3) @binding(0)`.

| Смещение | Поле | Тип |
|---|---|---|
| 0 | `seconds` | `f32` |
| 4 | `lit` | `u32` |
| 16 | `renderOffset` | `vec3i` |
| 32 | `sunDirection` | `vec3f` |
| 48 | `eyePosition` | `vec3f` |
| 64 | `shadowDirection` | `vec3f` |

Минимальный размер привязки uniform — 80 байт. Остальные привязки группы 3 — текстура глубины сцены для вариантов Liquid и буфер хранения `bloxdSpTextureLayers`.
