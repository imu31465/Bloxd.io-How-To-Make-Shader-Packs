# Документация по шейдер-пакам Bloxd.io

Неофициальное руководство по шейдер-пакам для WebGPU-рендерера Bloxd.io. Здесь собраны материалы о создании, реализации, проверке и распространении паков, справочник API и сведения об устройстве движка.

## Текущая спецификация

- Текущая версия API: **5** (`pack.json` обязан объявлять `apiVersion: 5`)
- Цель: WebGPU-рендерер
- Шейдерные хуки: 9 (Terrain / Liquid / Model × Vertex / Surface / Light)

Впервые создаёте шейдер-пак? Начните с [Начало работы](getting-started/). Нужна справка по API? Откройте [Справочник по API](api/).

> Эта документация не является официальным ресурсом разработчиков игры. Внутреннее устройство движка — детали реализации, которые могут меняться с обновлениями; описание поддерживаемого поведения см. в справочнике API.
>
> Это руководство создано с помощью ИИ; точность не гарантирована. Проверяйте по реальному поведению в игре. Продолжайте проверять рецепты по экрану загрузчика и компиляции в игре.
>
> Пакеты содержат только код WGSL: они не выполняют JavaScript и не отправляют сетевые запросы.

- **[Внутреннее устройство движка и исследования](internals/)** — пайплайн рендеринга, вызов хуков, заголовок движка, внутренности валидации и компиляции, зарезервированные идентификаторы, внутренности освещения/тумана, сэмплинг и реестр текстур, рендеринг моделей, измеренные данные.
- **[История версий](history/)** — с v1 по v5: изменения по версиям, шаги миграции, удалённые API.

## Метки статуса проверки

Каждая страница указывает версию API и статус проверки описанных сведений.

| Метка | Значение |
|---|---|
| Verified | проверено в игре |
| Analyzed | подтверждено анализом внутренней реализации |
| Partially Verified | подтверждено лишь частично |
| Experimental | экспериментально / не устоялось |
| Historical | материал для прошлой версии |

Сырые данные, извлечённые из движка (заголовок, реестр, измерения), живут в [Внутрянке движка и исследованиях](internals/); методология и журналы, стоящие за ними, отслеживаются в [журнале исследований](internals/research-log.md).
