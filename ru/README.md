# Документация по шейдер-пакам Bloxd.io

Неофициальное руководство по шейдер-пакам для WebGPU-рендерера Bloxd.io — от создания, реализации, валидации и распространения до спецификации API и исследования внутренностей движка.

## Текущая спецификация

- Текущая API: **5** (`pack.json` должен объявлять `apiVersion: 5`)
- Цель: WebGPU-рендерер
- Последняя проверка: 2026-11-03
- Целевой билд: `ab90qa.main.6188124c.js` (продакшен и предпрод идентичны — проверено по md5 `fc3322212d15be2445c0e8dfc9733fcc`)
- Шейдерные хуки: 9 (Terrain / Liquid / Model × Vertex / Surface / Light)

Впервые делаете шейдер-пак? Начните с [Getting Started](getting-started/) (на английском). Смотрите API? — [API Reference](api/) (на английском).

> Эта документация — не официальный ресурс разработчиков игры. Внутренности движка могут меняться с обновлениями — проверяйте целевой билд и статус проверки на каждой странице.
>
> Руководство создано с помощью ИИ; точность не гарантируется. Проверяйте по фактическому поведению в игре.
>
> Сама функция шейдер-паков — официальная функция внутриигрового UI, а паки — чистый WGSL (без выполнения JS и сети), поэтому с обычным кодом ничего опасного не происходит.
