# Создание шейдер-паков для Bloxd.io (Полное руководство)

Самодостаточное руководство по созданию и распространению шейдер-паков для Bloxd.io (только WebGPU-рендер).
**Текущий API — `apiVersion: 3`; он вышел в продакшн 2026-10-19**, и текущая игра отклоняет паки v1 и v2 при загрузке (сообщения о неверной версии API). Части I–VII ниже по-прежнему написаны на базе v2 и остаются действительными как концептуальная основа: читайте их как v2, а перед распространением примените изменения из части IX (`09-apiv3.md`). Руководство разбито на файлы по частям (это README — оглавление; рецепты вынесены в `03-recipes.md`). Предыдущий шаг миграции v1 → v2 описан в части VIII (`08-apiv2.md`). Часть IX также документирует внутрянку движка, восстановленную из продакшн-билда (§49–§54: вызов хуков, функция тумана с четырьмя режимами, реализация `bloxdOpaqueBehind()`, путь доставки `blockFlags` и конвейер валидации с измеренным хэшем заголовка).

> Это неофициальное руководство, оно не выражает позицию разработчиков. API может измениться без предупреждения.  
> Последняя проверка: 2026-10-20 (продакшн-раскатка v3 подтверждена сравнением бандлов; вызов хуков, туман, глубина и внутрянка `blockFlags` восстановлены из продакшн-билда — часть IX §49–§54). Поскольку публичного официального справочника по WGSL API найти не удалось, продолжайте сверять описания и рецепты с экраном загрузки и компиляцией в игре.  
> Функция шейдер-паков — официальная функция из интерфейса игры, а паки — чистый WGSL  
> (без выполнения JS и сети), так что обычный код безопасен.  
> Руководство создано при помощи ИИ; точность не гарантируется. Проверяйте по фактическому поведению в игре.
