# Сводка данных движка

> Целевой API: 5 · Статус: Analyzed

На этой странице собраны сведения об API, доступном шейдер-пакам. Подробности использования см. в [справочнике по API](../api/).

## Поверхность API

| Пункт | Спецификация |
|---|---|
| Версия API | `5` |
| Заголовок движка | 216 строк; см. [заголовок движка](engine-header.md) |
| Хуки | 9 (Terrain / Liquid / Model × Vertex / Surface / Light) |
| Варианты | 6 (strict × terrain / liquid / model) |
| Макросы | `BLOXD_STRICT`, `BLOXD_ALPHA`, `BLOXD_SCENE_DEPTH` |
| Uniform пака | 80 байт; см. [формат пака](../api/pack-format.md) |
| Поля uniform | `seconds` @0, `lit` @4, `renderOffset` @16, `sunDirection` @32, `eyePosition` @48, `shadowDirection` @64 |
| Имена текстур | Доступные именованные константы перечислены в [каталоге текстур](../api/texture-catalog.md) |

## API теней

- `bloxdShadow()` возвращает рассчитанный движком коэффициент тени солнца/луны.
- `bloxdAirShadow(t)` оценивает тень в точке между камерой и фрагментом.
- `bloxdShadowDirection()` возвращает направление света, создающего тень.
- `keepCircleShadows` — необязательное булево поле `pack.json`, сохраняющее прежние круглые тени.
