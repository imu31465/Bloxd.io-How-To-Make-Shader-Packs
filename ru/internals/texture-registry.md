# Внутреннее устройство реестра текстур

> Целевой API: 5 · Статус: Analyzed

На этой странице описано, как разрешаются имена текстур и как шейдер-паки на них ссылаются. Доступные авторам паков имена приведены в [каталоге текстур](../api/texture-catalog.md).

## Именованные константы

В паках следует использовать именованные константы формата `bloxdTextureId*`. При загрузке пака имена текстур разрешаются по реестру, поэтому числовые ID не нужно фиксировать в коде.

**Считайте имена API и не полагайтесь на числовые ID.** Расположение атласа и ID — детали реализации, которые могут меняться.

## Анимированные текстуры

Ссылайтесь на анимированную текстуру по базовому имени семейства, а не по номеру кадра. При выборке движок выбирает текущий кадр, поэтому паку не нужно самостоятельно переключать кадры.

Написания отдельных кадров не являются самостоятельными именованными константами для общего использования. Используйте базовые имена из каталога.

## Повернутые текстуры

Поворот каждой грани применяется во время выборки текстуры. Пакам не требуется напрямую выбирать внутренние предварительно повернутые слоты атласа.

## Примечания по выборке

- Выбирайте имена из [каталога текстур](../api/texture-catalog.md).
- Не полагайтесь на числовые ID или внутреннее расположение атласа.
- Как правило, оставляйте анимацию и поворот граней механизму выборки движка.
