# История версий

> Тип: исторический материал · Руководства по миграции API v1–v5

В этом разделе собраны изменения, шаги миграции и удалённые API версий v1–v5. Здесь описаны поведение API и пути перехода между версиями, а не идентификаторы билдов или даты проверки.

## Версии

| Версия | Руководство по миграции | Основные изменения |
|---|---|---|
| v1 | [v1](v1.md) | Первая версия API шейдер-паков |
| v2 | [v2](v2.md) | Переименование идентификаторов, `blockId` и доступ к глубине сцены |
| v3 | [v3](v3.md) | `blockFlags`, `bloxdPi` / `bloxdTau` и хуки Liquid |
| v4 | [v4](v4.md) | API текстур и ограничения strict-игр |
| **v5** | [v5](v5.md) | **Текущая** — `BloxdFlags`, хуки Model, API освещения и теней |

## Обработка старых версий

Текущая игра принимает только паки с `apiVersion: 5`. Старые паки нельзя загрузить без изменений. При переходе через несколько версий применяйте руководства по порядку, начиная с самой старой версии.

## Пути миграции

- Пак v4 → [руководство по миграции на v5](v5.md)
- Пак v3 → [v4](v4.md) → [v5](v5.md)
- Пак v2 → [v3](v3.md) → [v4](v4.md) → [v5](v5.md)
- Пак v1 → [v2](v2.md) → [v3](v3.md) → [v4](v4.md) → [v5](v5.md)

Текущая спецификация API приведена в [Справочнике API](../api/).
