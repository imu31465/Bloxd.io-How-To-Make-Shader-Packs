# API v1

> Статус: **Historical** — первая эпоха механизма шейдер-паков. Любой v1-пак отклоняется текущей игрой.

v1 был первым API шейдер-паков. v2 переименовал идентификаторы целиком ([руководство по v2](v2.md), таблица §32), поэтому главная ценность знания словаря v1 — **чтение старых дистрибутивов и старых руководств сообщества**.

## Словарь v1 (переименован в v2)

| v1 | начиная с v2 |
|---|---|
| `bloxdTime()` | без изменений (в v3 стал `bloxdSeconds()`) |
| `bloxdOriginOffset()` | без изменений (в v3 стал `bloxdRenderOffset()`) |
| `bloxdFaceBlock(position, normal)` | без изменений (удалён в v3) |
| `fogFactor` | `fogVisibility` (в v5 стал `fogAlpha`, инвертирован) |
| `engineColour` | без изменений (удалён в v5 — переработан в `litColour` и `bloxdLitColour()`) |
| — | `blockId` (добавлен в v2, в v3 стал `blockFlags`) |

Хуки были террейн / жидкость × vertex / surface — **6 хуков**, без light-хуков (light-хуки стали частью дефолтного шаблона только в v5). Идентификация блока была лишь угадыванием по цвету текстуры; `blockId` / `blockFlags` / `flags` ещё не существовало.
