# Структура пака

> Целевой API: 5 · Целевой билд: `ab90qa` · Статус: Verified

## Формат распространения

- **Формат**: один `.zip` или папка (загрузка папки — только десктопные браузеры)
- **Содержимое**: один `pack.json` (на верхнем уровне пака; регистр не учитывается) + 1–256 файлов `.wgsl`
- Несколько файлов `.wgsl` конкатенируются в один модуль, поэтому разбиение на файлы и поддиректории бесплатны. Ограничений на имена файлов нет. Конкатенация происходит в **словарном порядке по имени пути** (объявления на уровне модуля не зависят от порядка, так что это важно только для кода, зависящего от порядка инициализации `var`). Не-`.wgsl`-файлы (README и т.п.) игнорируются

## Лимиты размера и формата

| Пункт | Лимит | Сообщение при превышении |
|---|---|---|
| размер zip | 32 МБ | `The zip is over 32 MB.` |
| записи zip | 1 024 | `The zip has more than 1024 entries.` |
| размер `pack.json` | 64 КБ (UTF-8) | `pack.json is over 64 KB.` |
| число файлов `.wgsl` | 256 | `The pack has more than 256 .wgsl files.` |
| суммарный исходный код `.wgsl` | 256 КБ (UTF-8) | `The pack's .wgsl files are over 256 KB in total.` |
| форма zip | без zip64 / split / шифрования; store или deflate; без дублирующихся путей | каждое отклоняется собственным сообщением |

Все файлы должны быть валидным UTF-8.

## Советы по запаковке

Если zip хранит всё под одной общей корневой папкой, этот префикс срезается автоматически (функция "Compress" в macOS работает как есть; `__MACOSX`, файлы с префиксом `._` и `.DS_Store` исключаются автоматически). Посторонние файлы на корневом уровне ломают определение верхнего уровня, поэтому самый безопасный способ — запаковать `pack.json` и файлы `.wgsl` напрямую (проверьте, что `pack.json` оказался в корне zip).
