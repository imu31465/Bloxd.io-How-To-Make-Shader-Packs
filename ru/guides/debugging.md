# Советы по отладке

> Целевой API: 5 · Целевой билд: `v98qt8` (2026-11-08, прод и preprod) · Статус: Verified (портировано на текущий API — рекомендуется перепроверка на устройстве)
- Слишком светлые пещеры → не хватает нелинейной кривой `skyLight` (рецепт пещер R2 / R9.9)
- Выжженные дни → снижайте экспозицию до ACES
- Слишком тёмные ночи → обеспечьте минимальный ambient (ночной `skyLightColour` по предпосылке почти чёрный)
- Слишком дымные дали → снижайте воздушные коэффициенты
- Всё оранжевое вокруг факелов → снижайте долю тёплого смешения (оставьте немного сырого крашеного света)
- Блоки почти сплошь белые → суммарный выход light-хука превышает 1.0 (clamp дальше по потоку отсутствует). Заканчивайте `clamp(col, vec3f(0.0), vec3f(1.0))`
- Белые без добавок → un-fog-инверсия делением тумана. Откажитесь от un-fog; пересоберите от `s.colour`, а туман подмешайте `mix`-ом один раз в конце
- Эмиссивные блоки не светятся → пропущено досложение emission в рецептах пересборки. Добавьте `+ s.emission * (1.0 - l.fogAlpha)`
- Ночью выглядит неправильно только на освещённых гранях → затемняйте не только цвета теней; гасите весь готовый цвет движка (`engineColour`) ночью. Чтобы сохранить локальные лампы, ослабляйте затухание через `blockLight` / `heldLight` ([Дизайн ночных видов](night.md))
- Тень не углубляется ни при каком `pow(skyLight, γ)` → `l.skyLight` приходит пост-лифт (раздел 10). Переходите на инверсию + порог R9.12
- Настройка площади/плотности тени → см. гайд по настройке R9.12 (площадь = порог `shTh` / кромка = `shSoft` / темнота ядра = двухточечный сдвиг минимального ambient и небесного рассеяния)
