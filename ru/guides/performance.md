# Производительность

> Целевой API: 5 · Целевой билд: `xkg8x` · Статус: Verified (практика на основе замеров)

Хуки пака выполняются на каждом фрагменте (на всех пикселях террейна / жидкостей / моделей), поэтому решения по стилю заметно двигают частоту кадров.

## Первые факты

- **Light-хук — финальная стадия**: он выполняется для каждого нарисованного пикселя террейна, жидкостей и моделей — это большая часть экрана
- **Паки работают на WebGPU**: оценивайте стоимость исходя из диапазона GPU, включая мобильные
- Лимит размера загрузчика (256 KB `.wgsl`) — это ещё и практический потолок **времени компиляции**

## Лестница стоимости (дёшево → дорого)

| Операция | Стоимость | Примечание |
|---|---|---|
| `mix` / `clamp` / арифметика | ◎ минимальная | |
| чтение входов (`l.skyLight`…) | ◎ | из uniform/вершинных атрибутов |
| `smoothstep` / `pow` | ○ | `pow` зависит от экспоненты |
| `sin` / `cos` | ○ | основа анимации |
| `dot` / `normalize` | ○ | |
| `bloxdTexel()` (сэмпл текстуры) | △ | дешевле на высоких мипах |
| `dpdx` / `dpdy` / `fwidth` | △ | только surface/light-хуки |
| ветвление (`if`) | △ | WGSL может вычислять обе ветки; условия уровня uniform (проверки флагов) дёшевы |
| hash-шум (много `sin`/`fract`) | △ | гейтить микробамп-эффекты по дистанции |

## Практика

1. **Гейтите эффекты на грани, которым они нужны** — отбор по `flags` бьёт «+20% везде»
2. **Сбрасывайте детализацию с расстоянием** — ранний выход, когда `distance(surface.position, bloxdEyePosition())` превышает порог
3. **Используйте мипы** — `bloxdTexel(id, uv, mipLevel + 1.0)` даёт усреднение на ¼ разрешения ([разобранные примеры](../api/texture-api.md#разобранные-примеры))
4. **Для правок цвета предпочитайте surface-хуки** — light-хук — финальная стадия по всем пикселям
5. **Добавляйте детализацию постепенно и сравнивайте FPS** ([тестирование](testing.md))
6. **Guard'ы `#ifdef` не экономят время выполнения** — варианты — это единицы компиляции; экономия времени выполнения приходит от флагов и дистанции

## Замеры

- Сравнивайте FPS с паком и без него через devtools браузера (панель производительности / статистика WebGPU)
- Замеряйте по отдельности сцены, насыщенные террейном (лес, богатый тенями), и воду (хуки жидкостей)
- Проверьте мобильное железо — оно может быть в десятки раз медленнее
