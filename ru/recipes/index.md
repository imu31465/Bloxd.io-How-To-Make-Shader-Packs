# Рецепты

Примеры кода, сгруппированные по задачам. Объяснение принципов работы приведено в [Руководствах](../guides/). Примеры используют терминологию API v5 (`flags`, `bloxdLit()`, `fogAlpha`, `bloxdSeconds()`) и содержат проверки для всех шести вариантов (strict × terrain / liquid / model).
